TCP is a connection-oriented transport protocol.

Before data is exchanged, TCP establishes a connection between the communicating endpoints.

TCP provides reliable delivery by using acknowledgements, sequence numbers, and retransmission.

TCP also provides flow control so that a sender does not overwhelm the receiver.

Congestion control allows TCP to adapt its transmission rate based on network conditions.

UDP is a connectionless transport protocol. It does not provide TCP's guarantees of reliable delivery, ordering, or congestion control.

UDP is often useful when low latency is more important than guaranteed delivery, such as in some real-time applications.
